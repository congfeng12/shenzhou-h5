方向键移动和选择，与人物相邻后按确定交谈。

↑ ↓ ← → 移动　Enter / F1 确定　Esc 返回／取消
F5 / M 打开游戏菜单　F2 / N 卸下装备

鼠标／触屏：在大地图上点一格，角色会像按方向键那样一步步走过去，遇到障碍会绕开；在标题和菜单里，鼠标悬停到哪一项，原版光标就移到哪一项（深色反白），只有点在按钮上才会触发该项，点空白处不响应。右上角「菜单」按钮一键开关游戏菜单，Esc 逐层返回。

请在游戏菜单中保存进度。存档保留在当前浏览器，也可以导出备份；双击此 HTML 文件即可离线游玩。

画面按原版 160×100 逐像素输出，锁定比例缩放不拉伸；地图视野保持原版 10×5 格。手机可直接点画面操作。

右上角的全图鉴列出原版数据表中的道具、装备、法术、属性、前缀与人物；作弊可直接改写当前运行的原版引擎内存（属性、持有道具、已学法术），改完记得在游戏菜单里正常保存。

存档备份

先在游戏内执行保存，再导出备份。导入后将返回标题画面，请选择“旧的回忆”读取进度。

全图鉴

数据直接取自原版 GameSource.dat 的道具、法术、前缀、装备与敌人表；持有数量与已学状态读取当前游戏内存。

作弊

修改立即生效于当前运行的原版引擎内存；关闭面板后回到游戏即可看到变化。要在下次开机保留，请在游戏菜单里正常保存进度。
